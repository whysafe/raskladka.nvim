# raskladka.nvim: ghbdtn → привет

Плагин для Neovim, который исправляет текст, набранный не в той раскладке: слово под курсором, выделение или последнее слово прямо в режиме вставки, не выходя из него. Нужен всем, кто пишет в Neovim то по-русски, то по-английски: комментарии, коммиты, заметки в Markdown.

```
пишу ntrcn|          <M-r>  →   пишу текст|
Ghbdtn? rfr ltkf/    :Raskladka  →   Привет, как дела.
руддщ цщкдв          <leader>ru  →   hello world
open the afqk        выделить и <leader>ru  →   open the файл
```

## Установка

lazy.nvim:

```lua
{ "whysafe/raskladka.nvim", opts = {} }
```

packer или любой другой менеджер: подключите `whysafe/raskladka.nvim` и вызовите `require("raskladka").setup()`.

## Использование

| Где | Клавиши | Что делает |
|---|---|---|
| Обычный режим | `<leader>ru` | исправляет слово под курсором |
| Визуальный режим | `<leader>ru` | исправляет выделение |
| Режим вставки | `<M-r>` | исправляет последнее набранное слово, вы продолжаете печатать |
| Команда | `:Raskladka`, `:'<,'>Raskladka`, `:%Raskladka ru` | то же самое, `ru` или `en` задают направление явно |

Каждое исправление отменяется одним `u`. Справка внутри редактора: `:help raskladka`.

```lua
require("raskladka").setup({
  keymaps = {
    normal = "<leader>ru",  -- false, чтобы не создавать привязку
    visual = "<leader>ru",
    insert = "<M-r>",
  },
  skip_technical = true,    -- не трогать ссылки, почту и пути
})
```

## Как он решает, что исправлять

- **Слово целиком, со знаками.** На месте русских «б», «ю», «ж», «э», «х», «ъ», «ё» в латинице стоят `, . ; ' [ ] \``. Поэтому `k.,k.` — одно слово, и это «люблю». Для курсора и выделения границы слова считаются так же.
- **Пунктуация остаётся пунктуацией.** Точка и запятая в конце русского слова при переводе в английский не превращаются в `/` и `?`: `руддщ, цщкдв!` → `hello, world!`. В обратную сторону `?` и `/` после латинского слова становятся запятой и точкой, как их и набирали.
- **Правильные слова не трогаются.** В набранном не в той раскладке слове почти нет гласных: «ghbdtn», «rfr», «руддщ». Плагин переводит слово, если в нём гласных не больше четверти, а после перевода их стало больше. Поэтому в `пишу ntrcn в Vim` исправится одно слово. Если подходящих слов нет, а исправить просили, переводится всё выделенное.
- **Ссылки, почта и пути** (`https://…`, `name@site.ru`, `~/.config`) остаются как есть.

## Ограничения

Правило про гласные проверено на обычном тексте:
- в русском абзаце из 57 слов оно не сочло неправильным ни одного;
- в английском из 75 слов ошиблось на 5: bring, Thursday, Thanks, went, trip, где согласных много.

Это важно, только если выделить английское предложение с одним русским словом внутри. Для одного слова или чистого куска текста ошибки нет, а `:Raskladka ru` переводит всё без эвристики.

Слова, где после перевода гласных столько же, но нет ни одной, вроде `ujl` («год»), в смешанном выделении могут остаться непереведёнными. Курсор на слове и `<leader>ru` исправят их всегда.

## Как устроено

```
lua/raskladka/convert.lua   таблицы раскладок, разбор на слова, эвристика; без vim API
lua/raskladka/init.lua      работа с буфером, курсором и выделением
plugin/raskladka.lua        команда :Raskladka
doc/raskladka.txt           справка :help raskladka
tests/                      свой маленький раннер без зависимостей
```

В LuaJIT и Lua 5.1 нет модуля `utf8`, поэтому символы перебираются шаблоном по байтам UTF-8. По этой же причине при посимвольном выделении конец дотягивается до последнего байта русской буквы: метка `'>` указывает на её первый байт.

## Тесты

```bash
lua tests/run.lua                    # логика перевода, любой Lua 5.1+
nvim --headless -l tests/run.lua     # плюс проверки в настоящем редакторе
```

20 тестов:
- 11 на логику перевода, эвристику и границы слов;
- 9 внутри Neovim: привязки нажимаются через `feedkeys`, в том числе `<M-r>` посреди набора в режиме вставки, а ещё выделения с русскими буквами, диапазоны, команда с направлением и отмена одним `u`.

CI гоняет логику на Lua 5.1, 5.4 и LuaJIT, а редактор на Neovim 0.9.5, stable и nightly.
